✅ IF YOU WANT MANUAL CONTROL:

   👉 RIGHT-CLICK: setup-and-run.ps1 → Run with PowerShell

   OR in Command Prompt:
   
      powershell -NoProfile -ExecutionPolicy Bypass ^
        -File setup-and-run.ps1

   Options:
   - setup-and-run.ps1                    (Full setup)
   - setup-and-run.ps1 -SkipJavaSetup     (Skip Java check)
   - setup-and-run.ps1 -SkipMavenSetup    (Skip Maven check)

❓ TROUBLESHOOTING:

   Nothing appears for 2 minutes?
   → Check Task Manager → Applications → Should see:
     • java.exe (Backend)
     • java.exe (Frontend)

   "PowerShell cannot run this script"?
   → Right-click setup-and-run.ps1
   → Properties → Check "Unblock" → OK
   → Right-click → Run with PowerShell

   Still stuck?
   → Read SETUP_INSTRUCTIONS.md for manual setup
